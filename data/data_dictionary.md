# Data Dictionary — Healthcare Operations & Patient Access Analytics

This dataset is synthetic and created specifically for an independent portfolio project. It does not contain real patient information.

| Column | Description |
|---|---|
| appointment_id | Unique identifier for each appointment |
| appointment_date | Date the appointment was scheduled to occur |
| specialty | Clinical specialty associated with the appointment |
| location | Healthcare facility/location |
| provider | Provider assigned to the appointment |
| appointment_type | Type of appointment |
| patient_type | New or returning patient |
| insurance_type | Primary insurance/payment category |
| scheduled_lead_days | Number of days between scheduling and appointment date |
| wait_time_minutes | Patient wait time in minutes; 0 for cancelled/no-show appointments |
| appointment_status | Completed, Cancelled, or No-show |
| appointment_duration_minutes | Scheduled appointment duration |
| patient_satisfaction_score | Synthetic 1–5 satisfaction score for completed visits |

## Suggested business questions

1. What is the overall appointment completion, cancellation, and no-show rate?
2. Which specialties have the highest no-show or cancellation rates?
3. Which locations have the longest average patient wait times?
4. Does longer scheduling lead time relate to missed appointments?
5. Which appointment types have the strongest operational performance?
6. Which providers or locations show unusually high wait times?
7. How does patient satisfaction change as wait time increases?
8. What operational improvements should leadership prioritize?

## Important note

This is an independent, synthetic portfolio dataset. It is not employer/client data and should not be presented as such.
