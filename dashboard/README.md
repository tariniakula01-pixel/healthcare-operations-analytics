# Power BI Dashboard

## Overview

This Power BI dashboard provides an end-to-end view of healthcare appointment operations, patient access, patient experience, and provider workload.

The dashboard translates appointment-level data into actionable KPIs, operational trends, performance comparisons, and business recommendations.

## Dashboard Pages

### 1. Executive Overview

Provides an executive-level summary of appointment performance.

Key components:
- Total appointments
- Completion rate
- Cancellation rate
- No-show rate
- Average wait time
- Average patient satisfaction
- Monthly appointment trends
- Appointment outcome distribution
- Interactive filters for specialty, location, and appointment type

### 2. Operations & Access Analysis

Focuses on appointment access and operational performance.

Key analyses:
- No-show rate by specialty
- Cancellation rate by location
- Missed appointments by scheduling lead time
- Specialty and location performance comparison
- Operational findings and improvement opportunities

### 3. Patient Experience & Provider Performance

Examines patient experience and provider workload.

Key analyses:
- Patient satisfaction by wait time
- Wait time distribution
- Provider workload based on scheduled minutes
- Appointment performance by appointment type
- Key operational recommendations

## Key KPIs

| KPI | Purpose |
|---|---|
| Total Appointments | Measures appointment volume |
| Completion Rate | Measures completed appointment percentage |
| Cancellation Rate | Measures cancelled appointment percentage |
| No-Show Rate | Measures missed appointment percentage |
| Average Wait Time | Measures patient waiting time |
| Average Patient Satisfaction | Measures completed-appointment satisfaction |

## Tools

- Power BI
- DAX
- SQL
- CSV
- Business Analysis

## Data

The dashboard uses a synthetic healthcare appointment dataset created for this independent portfolio project.

The dataset contains 1,200 appointment records covering specialties, locations, providers, appointment types, patient types, insurance types, scheduling lead time, wait time, appointment status, duration, and patient satisfaction.

## Business Value

The dashboard is designed to help healthcare operations teams identify missed-appointment patterns, understand access and wait-time issues, evaluate provider workload, and prioritize data-driven operational improvements.
